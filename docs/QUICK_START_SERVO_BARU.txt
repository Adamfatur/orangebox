   Periksa LABEL di servo fisik:

   ✅ BENAR (Positional):          ❌ SALAH (Continuous):
      • "MG996R"                      • "360° Servo"
      • "Standard Servo"              • "Continuous Rotation"
      • "0-180°"                      • "Full Rotation"

   ⚠️  JIKA SALAH TIPE → JANGAN PASANG! Return/exchange dulu!

🔧 STEP 2: INSTALASI HARDWARE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

   1. Matikan semua servo:
      $ python3 scripts/emergency_stop_servos.py

   2. Lepas 4 servo LAMA (continuous rotation):
      • Channel 0 (Lock Left)
      • Channel 2 (Lock Right)
      • Channel 4 (Corner A)
      • Channel 6 (Corner B)

   3. Pasang 4 servo BARU (MG996R positional):
      • Channel 0 → Lock Left (kabel: COKLAT=GND, MERAH=VCC, ORANGE=PWM)
      • Channel 2 → Lock Right
      • Channel 4 → Corner A
      • Channel 6 → Corner B

   4. Periksa wiring ketat (tidak longgar)

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

   $ python3 scripts/quick_servo_diagnostic.py

   Test servo baru satu per satu (CH 0, 2, 4, 6):
   • Command 0° → Servo BERHENTI di 0° (NOT rotating) ✅
   • Command 90° → Servo BERHENTI di 90° ✅
   • Command 180° → Servo BERHENTI di 180° ✅

   ❌ Jika servo BERPUTAR TERUS (360°) → WRONG TYPE! Ganti servo!

   $ cp config.py config.py.OLD_3SERVO_BACKUP

   $ cp config.py.READY_FOR_7_SERVO config.py

   $ grep "SERVO_L1_CORNER_A_CHANNEL" config.py

   $ grep "SERVO_L1_LOCK_LEFT_CHANNEL" config.py
   # Output harus: SERVO_L1_LOCK_LEFT_CHANNEL = 0 (bukan None!)
